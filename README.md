# Семейная тарелка

Подбор простых и полезных домашних блюд для семьи с детьми: выбор основы и соуса, рандомайзер по времени суток, БЖУ и минералы для детей разных возрастов, список покупок с заменами.

- `index.html` — готовый сайт (база рецептов встроена).
- `db.json` — база: состав продуктов на 100 г и 50 рецептов с рассчитанной пищевой ценностью.
- `src/` — исходники: `ingredients.py`, `recipes.py`, `build.py` (пересчёт `db.json`), `template.html`.

Пересборка: `cd src && python3 build.py`, затем подставить `db.json` в `template.html` вместо `/*DB*/`.

Нормы — ориентировочные, по МР 2.3.1.0253-21. Сайт не заменяет консультацию педиатра.
