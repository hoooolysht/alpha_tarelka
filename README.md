# Семейная тарелка

Интерактивная «тарелка»: выбираете белок, гарнир, жиры и овощи — круговая диаграмма показывает, насколько приём пищи закрывает норму белков, жиров, углеводов и клетчатки для ребёнка или взрослого. Под тарелкой — подходящие рецепты (60 шт.) со списком покупок.

- `index.html` — готовый сайт (база рецептов встроена).
- `db.json` — база: состав продуктов на 100 г и 60 рецептов с рассчитанной пищевой ценностью.
- `src/` — исходники: `ingredients.py`, `recipes.py`, `extras.py` (названия, кухни, добавки), `plate.py` (продукты для тарелки), `build.py` (пересчёт `db.json`), `template.html`.

Пересборка: `cd src && python3 build.py`, затем подставить `db.json` в `template.html` вместо `/*DB*/`.

Нормы — ориентировочные, по МР 2.3.1.0253-21. Сайт не заменяет консультацию педиатра.
